# 💈 Barber Club

O **Barber Club** é o site de uma barbearia moderna desenvolvido desde a etapa de UX/UI Design até a implementação do código com HTML 5 e CSS 3. O projeto passa pelo mapeamento de fluxo, prototipação e construção de uma interface responsiva e semântica.

---

## 🛠️ Tecnologias e Ferramentas

* **Figma:** UX/UI Design, Wireframes, Design System e Protótipo Navegável.
* **HTML5 Semântico:** Estruturação limpa e focada em acessibilidade.
* **CSS3:** Layouts modernos desenvolvidos com Flexbox, CSS Grid e Media Queries para total responsividade.
